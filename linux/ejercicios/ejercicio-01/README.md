# Ejercicio 01 - Comandos básicos de Linux

En este ejercicio practiqué los siguientes comandos:

- `mkdir` → crear una carpeta nueva
- `cd` → moverme dentro de esa carpeta
- `pwd` → comprobar en qué ruta estaba
- `touch` → crear un archivo vacío
- `ls` → listar el contenido de la carpeta

## Aprendizaje

Aprendí que las rutas relativas dependen de en qué carpeta esté situada la terminal en ese momento, y que `pwd` es muy útil para no perderme
